# Roadmap Folder

In this folder is different projects that each one is good for learning some concepts that are maybe being useful and starter point to real world projects.


<details>
<summary>Crypto Machine</summary>
  This project is a greate start to working with JSON, work with files in python, working with Dictionaries in python and user managing. This is a very simple project that in version 2 user can register and each get a unique key that is the key to decode and encode the string that they have we store the data in JSON file, we write the data and read the data when it is needed.
</details>


<details>
<summary>Marble trading Game</summary>
  This is a very simple betting game that each time user want to play thy chose an amount of money that they want to play, and then they should guess what color would be got out and if they were right they get the double amount of bet else they will lose the money, when the money gets below 500 game would be stopped.
</details>



<details>
<summary>Math Tutor</summary>
  This is a simple math tutor that user can play in different range and operators and then answers to question and operator and range of those question all going to be set by the user. At the end user can get how much time spend, how many correct answers they have and see all the question.
</details>


<details>
<summary>Number guessing</summary>
  This is a simple game that user can choose the level that want to play and then base on level have chances to find the right number. Each time the user wants to play the game, a random number between the range of 1 to 100 will be generated and then user try to find it. When they find it the game would be stopped and congrats them, if not, and they use all the chances they have the game will show them the correct number and then give them the option to play again or leave the game.
</details>
